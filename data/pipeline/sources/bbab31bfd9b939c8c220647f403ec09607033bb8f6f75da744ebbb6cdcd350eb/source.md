## L1 违规案例层（40 条）

### A 组：总局 2023 典型案例（S1/S2，2023-10-10，辽宁局转发）

**#001　夸大保险责任（重疾险）｜完整性A｜isolation_group=G01**
- `[官方]`：某保险公司销售人员推荐某款重大疾病保险时，宣称该产品"大大小小的疾病全都赔，只要消费者有病，保险公司先给钱看病"。实际上保障范围仅包括重大疾病，一般疾病并不赔付。监管提示：根据《保险法》及相关保险监管规定，保险机构销售保险产品时应向消费者说明合同内容，不得欺骗消费者，不得隐瞒与合同有关的重要情况。
- 上下文：投诉场景，重疾险｜预期结论`[我方]`：no / 夸大保险责任（建议词表增补 EXAGGERATE_COVERAGE）
- 适用条文：当时=《保险法》第116条；当前映射=《保险销售行为管理办法》禁止欺骗条款（条款号待核）
- 关键证据`[官方]`："大大小小的疾病全都赔，只要消费者有病，保险公司先给钱看病"
- 缺失信息：机构名、发生时间｜验证状态：已见官网全文｜usage_scope=dev_only

**#002　收益类比存款（电销分红险）｜A｜G01**
- `[官方]`：电销人员称该款产品"收益比银行存款高，相当于按月存钱，同时还有保险保障"。
- 预期结论`[我方]`：no / MISLEADING_COMPARISON+EXAGGERATE_RETURN｜条文：同上待核
- 关键证据`[官方]`："收益比银行存款高，相当于按月存钱，同时还有保险保障"｜验证状态：已见官网全文

**#003　隐瞒产品属性（网络平台"少儿教育金"）｜A｜G01**
- `[官方]`：某保险代理公司网络平台推介热销"少儿教育金"，宣称"该款产品收益高于银行利息"，未提示是保险产品；消费者购买一年后发现不能随时"支取"、中途退保有损失；再查销售页面时已下架，购买页面已被删除。
- 预期结论`[我方]`：no / HIDE_TERMS+MISLEADING_COMPARISON；页面删除情节涉销售可回溯要求
- 适用条文：当时=《保险法》第116条+《互联网保险业务监管办法》（2021-02-01施行）｜验证状态：已见官网全文

**#011　业务员代抄风险提示语+诱导回访｜A−｜G05**
- `[官方]`：某寿险公司业务员黄某销售年金保险（分红型）时承诺并夸大收益，未对现金价值、退保损失等重要内容进行解释，引导投保人李某在回访时对全部问题回答"是"，并代李某抄录风险提示语。经查代抄录属实，监管机构对该公司采取监管谈话措施。官方引《人身保险新型产品信息披露管理办法》抄录与回访要求。
- 预期结论`[我方]`：no / EXAGGERATE_RETURN+HIDE_TERMS（流程违规：代抄、诱导回访）

**#012　朋友圈炒停｜A−｜G06**
- `[官方]`：保险代理人马某在微信朋友圈发布"购买返还型健康保险最后机会""重大疾病保险费率调整"等"炒停"信息，以"即将停售"概念误导消费者。官方引《人身保险销售误导行为认定指引》《人身保险公司保险条款和保险费率管理办法》，并指出"返还型健康险"表述不准确、属混淆健康保险特点。
- 预期结论`[我方]`：no / 炒停（词表增补 STOPISELL_HYPE）+虚假宣传
