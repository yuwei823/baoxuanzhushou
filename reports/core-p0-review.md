# P0 核心法规全文及规则审阅

日期：2026-10-11。审阅者：实施 agent（Codex），并非外部法律专家审签。

## 本轮范围

用户已要求暂缓《中华人民共和国保险法.doc》抽取。本轮 `official-v1-2026-10-11` 仅包含三份本地正式来源：保险销售行为管理办法 DOC（50 条）、金融产品网络营销管理办法 PDF（39 条）、互联网保险业务监管办法 DOC（83 条）。保险法继续登记为用户暂缓的待扩展来源，消费者权益指导意见保留为参考，均不参与本快照。

## 审阅过程与结论

本轮逐份读取全部 172 条本地抽取原文，审阅了适用主体、商业营销与销售阶段、互联网渠道、产品类型、重要未决事实和例外。程序再检查每条原文能从保存的抽取产物重建、条号唯一且连续、条文 ID 使用实际条号、检索块保持完整父条。官方来源只辅助核验版本和抽样正文，未下载替换本地文件；没有声称完成全文与官网逐字比对。

`scripts/core_rule_review_data.py` 保存逐条范围决定及补充义务；`article-review-ledger.jsonl` 为 172 条各记录范围、排除理由或核验条件、规则关联、审阅者类别。`review.json` 将本次审阅绑定源文件、抽取产物、原文和规则卡内容的哈希。`verified` 在本快照中明确指这次实施 agent 的本地来源/映射审阅，不能当作法律专家意见或模型效果认证。

完整条文作为检索块保留，包括条文内部款项和例外；不单独拆掉例外。规则卡另有 `supporting_article_ids` 指向定义和适用范围，以便后续检索补齐。混合义务条文的范围类别不意味着整条每一款都能从创意素材判断：实际审核仍必须逐规则核验适用事实，内部制度及实际许可不得伪称通过。

## 修正及关键例外

- 修复章节标题被附到前一条末尾、网络营销办法第39条混入问答标题/网页链接/手机扫码提示的解析问题。只排除明确章节及该本地 PDF 的页面导航；原始抽取 JSON 和原附件完整保留，并在快照中另存副本。
- 保险销售办法第18条是未经授权**发布**销售宣传信息，不能泛化成未取得真实执业资格。
- 互联网保险办法第15条第（五）项直接禁止以监管机构及其工作人员名义或形象进行商业宣传；恢复该引用，纠正上一轮把它当一般转引条款而移除的判断。
- 销售办法第25条合理简化提示需同时满足投保人同意、权利义务简单、三个月内再次购买同一公司同一产品；不能扩展成免除第26条责任免除说明。
- 互联网保险办法第14条第（三）项针对规定的人身保险新型产品销售/详情页，要求不小于产品名称字号的黑体不确定性提示。小字不可读或缺少相对字号证据时必须保留未决事实。
- 互联网保险办法第16条政府因公共利益指定平台录入投保信息的例外，不扩展到任何第三方平台。
- 金融产品网络营销办法第17条引用广告代言规则；当前语料没有具体广告代言法条，因此记录外部核验，不以公众人物出现或该转引条文本身直接认定违法。
- 销售办法第28条并非一概禁止不匹配后继续购买，包含风险说明并确认自主选择的条件；真实投保信息仍需外部证据。
- 互联网保险办法第61条允许满足条件的保险中介转委托，第64、68条则对银行及互联网企业代理另作限制；第52条地域扩展和第64条特定银行例外均保留。
- 金融网络营销办法第19条商标整体具有其他含义且不易误认的例外，不能把正文包含“保险”一词等同未授权账号/商标。

## 保留的核验边界

许可、账户、授权、合约、消费者评估和支付等真实事实按外部核验规则登记，不属于本地 demo 已核实事实。未提供完整页面、渠道、产品或合同信息时，后续审核输出待复核；跨法规各自适用条件并列保留。本阶段验收是明确范围的语料工程及来源映射验收，效果、三态审核和真实百炼调用留待 P1/P3 验证。
