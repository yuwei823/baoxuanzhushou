# RAG 补充搜索开启/关闭真实对照

日期：2026-10-14

## 测试口径

- 相同模型：`qwen3.7-plus`，关闭 thinking。
- 相同规则集：`official-v3-2026-10-12`，46 张规则卡。
- 相同参数：每批最多 4 条规则，模型并发 8。
- 相同数据：5 条已暴露的 provisional 开发案例，每种模式各运行 1 次。
- `targeted`：执行查询向量、BM25、RRF，并按批次补充相关法条。
- `none`：严格关闭查询向量、BM25、RRF和检索排序；仍检查全部 46 条规则，并保留规则直接/支持法条。

本报告不是正式 P3 准确率评估。案例少、已经暴露、每种模式仅运行一次，不能据此估计生产准确率或统计显著性。

## 结果

| 指标 | 开启 targeted | 关闭 none | 关闭后的变化 |
|---|---:|---:|---:|
| 全部开发检查通过 | 5/5 | 4/5 | -1 例 |
| 审核成功完成 | 5/5 | 4/5 | -1 例 |
| Prompt token | 554,781 | 446,506 | -19.5% |
| 总 token | 602,664 | 493,297 | -18.1% |
| Prompt 字符总量 | 1,536,895 | 1,271,769 | -17.3% |
| 单批最大 Prompt 字符 | 34,264 | 30,415 | -11.2% |
| P50 延迟 | 28.906 秒 | 28.032 秒 | -3.0% |
| P95 延迟 | 43.666 秒 | 32.725 秒 | -25.1% |
| 请求耗时合计 | 942.359 秒 | 909.482 秒 | -3.5% |
| Embedding 调用 | 5 | 0 | -5 |
| 结构修复 | 3 | 3 | 持平 |
| 最终技术失败 | 0 | 1 | +1 |

P95 仅由 5 个样本计算，受单次服务波动影响很大，不应把 25.1% 当作稳定性能收益。

## 逐案例结果

| 案例 | 预期 | targeted | none |
|---|---|---|---|
| 明确违规 | non_compliant | 完成，通过 | 完成，通过 |
| 中性科普 | compliant | 完成，通过 | `invalid_model_output`，未形成结论 |
| 局部材料 | needs_review | 完成，通过 | 完成，通过 |
| 伪装科普的销售注入 | non_compliant | 完成，通过 | 完成，通过 |
| 科普改写 | compliant | 完成，通过 | 完成，通过 |

关闭 RAG 后的共同结论没有出现新的错判；唯一差异是中性科普案例在证据原句校验后仍无法得到合法模型输出。targeted 本轮也出现过 3 次同类校验错误，但通过结构修复恢复；none 出现 4 次，其中一批最终失败。

## 结论

严格关闭补充搜索可明显降低 Prompt 和 token，并完全取消查询 Embedding；中位延迟只改善约 3%。本轮 targeted 的工程通过数更好（5/5 对 4/5），因此当前仍保留 `targeted` 为默认配置。

这个结果尚不足以证明 RAG 提升准确率。此前的单次运行中 targeted 与不补充法条都曾在同一中性科普案例失败，说明模型输出具有波动。下一步应在人工核对的 20 条开发集与 40 条冻结测试集上重复比较三态结论、违规类型、条文引用、证据、技术失败率、token 和延迟。

## 原始证据

- `manifest.json`：规则集、模型、参数及代码哈希。
- `results.jsonl`：10 次完整响应与逐项检查。
- `summary.json`：聚合指标。
