# 实操题目：基于大模型的保险营销内容智能审核

## 一、任务背景
随着金融行业对外营销内容（图文、短视频等）数量激增，传统人工审核效率低、成本高，且难以应对日益复杂的合规要求。为提升自动化审核能力，需构建一套基于大模型的智能审核系统。自动判断一段金融营销内容是否违反上述任一规则，并给出违规理由、对应条文及置信度。
现有三篇核心监管文档作为审核依据，见附件：
1)《保险销售行为管理办法》
2)《金融产品网络营销管理办法》
3)《互联网保险业务监管办法》
这些文档涵盖文字表述、禁止用语、资质要求、风险提示等多个维度，部分条款存在隐含逻辑和上下文依赖。

## 二、任务要求（候选人需完成以下工作）
请设计并实现一个端到端的解决方案实现可运行demo原型，满足以下目标：
功能性要求
1.支持输入一段文本、或者一组图文，输出审核结论。
2.输出格式应包含：
(1)是否合规（yes/no）
(2)违规类型（如“夸大收益”、“无资质代言”等）
(3)引用的具体规则条文编号与原文
技术性要求
1.使用 百炼大模型 API 使用现有的主流agent开发框架/或者手写编码完成。
2.至少使用以下一种技术路径进行增强，包括不限于：
(1)Prompt Engineering
(2)RAG 
(3)Agent 
(4)Workflow
3.实现基本的效果评估模块
4.演示代码实现、架构图、关键设计说明
