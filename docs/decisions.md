## 按批次定向补充 RAG（2026-10-13）

保留 46 条规则全覆盖，将额外召回条文从“全局列表复制到每个批次”改为“文本全局相关性 + 当前批次法条相关性”的二次 RRF。批次相关性使用直接法条的 BM25 相似度及已建条文向量中心，不增加在线 Embedding 调用；候选必须同时处于文本和批次排名前列，每批最多 8 条、8,000 字符。直接条文和支持条文始终保留，完整 Prompt 仍受 90,000 字符硬预算保护。

## 文本调用参数

BAILIAN_TEXT_ENABLE_THINKING 可选布尔值；未设时不传该参数，使用服务默认行为。本地 qwen3.7-plus 设置 false，避免默认思考过程增加完整 JSON 响应等待。该参数仅作用于文本调用。依据：[百炼官方思考模式说明](https://help.aliyun.com/zh/model-studio/deep-thinking)。保留并发 2、单调用 45 秒、整体 150 秒及最多 16 次尝试限制。

## 长文本输入与上下文预算建议（2026-10-13，前端限制已实施，其余待评测）

- API 继续保留 **10,000 Unicode 码点硬上限**，不因模型标称上下文较大而直接放宽。
- 页面单次输入已限制为 **5,000 Unicode 码点**：计数器、粘贴截取和提交前校验使用同一上限。超过部分不会提交；建议用户按独立营销材料或逻辑章节拆分，3,000 码点以内作为常规区间。
- 除总字符数外，同时观察非空段落数和营销主张密度。建议超过 **60 个非空段落**时提示拆分，因为大量短段会扩大分段检索、候选条文和逐规则审核规模。
- 单批完整模型 Prompt 的工程分级暂定为：目标不超过 **60,000 字符**；60,000～75,000 为观察区；超过 75,000 必须优先收缩额外 RAG 召回或继续按规则分批；**90,000 字符为现有硬预算**。规则直接条文、支持条文、输入证据和适用条件不得为了压缩而静默删除。
- 超过 10,000 码点的材料应按完整营销资产或语义章节拆分审核，并保留各部分关系；不得机械截取前 10,000 字后给出整体合规结论。
- 上述数值是基于当前 46 条规则、hybrid RAG 和长材料故障修复得出的工程建议，不是模型能力边界或正式准确率结论。P3 需增加长度梯度和主张密度实验，比较结论、引用、覆盖、技术失败率、时延与 token 用量后再校准。
